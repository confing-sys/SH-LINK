# SH-Link Protocol v2.1

**SH-Link** — открытый, энергоэффективный и безопасный протокол для умного дома.  
Поддерживает радиоканалы 868/433 МГц и проводную шину RS-485.  
Версия 2.1 полностью устраняет известные уязвимости, обеспечивая:

- 🔐 Полную прямую секретность (PFS) на базе ECDHE + Ed25519
- 🛡️ Защиту от replay-атак с единым 40-битным счётчиком кадров
- 🔒 Защиту от downgrade-атак (уровень безопасности фиксируется при спаривании)
- ⏱️ Безопасную синхронизацию времени с монотонными эпохами координатора
- 🚫 Устойчивость к глушению и DoS (окно 128 кадров + экстренная ресинхронизация)
- 🧾 Централизованный ACL с подписями координатора и токенами делегирования
- 🧠 Аппаратную защиту ключей (ATECC608, SE050)

## Возможности

- 🇪🇺 Полное соответствие ETSI EN 300 220 для радио (LBT, 25 мВт на 868 МГц, 10 мВт на 433 МГц)
- 🧵 Проводной сегмент RS-485 — до 1200 м, до 32 устройств, питание по витой паре
- 🔀 Мульти-PHY — OOK, GFSK, MSK, 4‑GFSK (радио) + RS-485
- 🌐 Единое 16-битное адресное пространство
- 🔄 Кросс-интерфейсная маршрутизация через координатор с проверкой прав
- 🔒 Четыре уровня безопасности (L0–L3), привязанные к сеансовому ключу
- ⚡ Энергоэффективность: минимальный оверхед, спящие устройства, аппаратная фильтрация пробуждений
- 💻 Реализация на дешёвых МК (Cortex-M0+, ATmega) и распространённых трансиверах (CC1101, AX5043, MAX485)
- 🖧 Координатор можно развернуть на роутерах Keenetic с USB (включая Launcher KN-1221)
